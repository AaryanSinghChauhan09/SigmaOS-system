# SigmaOS-system

Init, service-manager, and system-orchestration component for SigmaOS.

## Development

Use the repository Makefile for the component's supported checks:

```bash
make build
make test
```

Changes should state lifecycle, failure-recovery, and privilege implications.
System integration status is tracked in the central [SigmaOS repository](https://github.com/AaryanSinghChauhan09/SigmaOS).
